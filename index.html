如何嵌入到 Google 協作平台 (Google Sites)？

  1. 開啟您的 Google 協作平台 編輯頁面。
  2. 在右側選單點擊 「插入」 ➔ 「嵌入」。
  3. 切換至 「嵌入程式碼」 頁籤。
  4. 把這個單一 HTML 檔案的完整程式碼全部複製並貼入，按下下一步並插入。
  5. 調整網頁區塊寬度與高度即可完美運作！

免費申請 Google Client ID 步驟指南

⚠️ 請使用個人一般 Gmail 帳號操作（學校 @edu.tw 教育帳號無權限開啟）。
  1. 開啟 Google Cloud Console 並使用個人 Gmail 登入。
  2. 點擊頂部建立新專案（名稱可填：ContactBook）。
  3. 左側選單進入 「API 和服務」➔「程式庫」，搜尋並啟用「Google Drive API」。
  4. 進入 「OAuth 同意畫面」，選擇 「外部 (External)」，填寫應用程式名稱與您的 Email。
  5. 進入 「憑證 (Credentials)」➔「建立憑證」➔選「OAuth 用戶端 ID」。
  6. 應用程式類型選擇 「Web 應用程式」，並在已授權的 JavaScript 來源新增此網頁的網址（如：https://sites.google.com 或目前的網址）。
  7. 按下建立後，複製生成的 「用戶端 ID (Client ID)」（格式為 xxx.apps.googleusercontent.com）並貼回系統中即可！
